InvoidHunter — как добавлять работы

1. Положи видео (.mp4 / .webm / .mov) в папку media/.
   Подпись на карточке = имя файла без расширения (BENZINOBOSS.mp4 -> "BENZINOBOSS").
   Хочешь обложку — положи рядом картинку с тем же именем: BENZINOBOSS.jpg
   (она станет постером видео и отдельной карточкой не покажется).
2. Если сайт открыт через локальный сервер (python -m http.server) — больше ничего не нужно,
   обнови страницу, и видео появится само.
3. Если сайт лежит на хостинге (GitHub Pages и т.п.) — перед загрузкой дважды кликни update_media.bat
   (или запусти: python update_media.py). Он обновит media_list.json. Затем залей всё на хостинг.
